## What this release contains

- **No full documents and no full histories.** The streams are regenerated from the pinned sources by the extraction
  scripts. Per-edit counts, runbooks and point maps contain identifiers (Wikipedia page ids, file paths, revision
  indexes, timestamps), chunk keys (hashes) and counts, not text.
- **Text excerpts.** The question files (`results/qa/questions_*.jsonl`), the audit sheet (`results/round2/audit_sheet.csv`),
  the second-model check (`results/round2/qcheck.csv`) and the saved retrieval contexts (release asset
  `results/qa/contexts*.jsonl`) contain sentences and chunks copied from the sources, and LLM-written questions,
  answers and verdicts derived from them.
- **No editor names or IP addresses.** Wikipedia user names were read only to drop bot edits and are not stored in any
  released file.

## Terms for derived text

- Text derived from Simple English Wikipedia (WIKI questions, evidence passages, contexts and the WIKI rows of the
  audit sheet and second-model check) is distributed under **CC BY-SA 4.0**. Attribution: the Wikipedia contributors of
  the article identified by the page id in each record (`https://simple.wikipedia.org/?curid=<doc_id>`, whose history
  lists the authors). Changes: wikitext converted to plain text with Markdown headings, sentences segmented, questions
  generated by an LLM. Adaptations must be shared under the same license.
- Text derived from the Kubernetes documentation is distributed under **CC BY 4.0** with attribution to The Kubernetes
  Authors and the file path in each record.
- Text derived from the CPython documentation is distributed under the **PSF License Version 2** with the notice
  "Copyright (c) Python Software Foundation; All Rights Reserved" and the file path in each record.
- Mixed files (for example the context files, which combine WIKI distractors with chunks of all three streams) carry
  the terms of each record's source; a record's stream is given by its question id.

## Model-generated content

Questions, answers and sentence-probe paraphrases were generated by qwen3:8b (Q4_K_M GGUF, Apache-2.0 model weights);
the second-model verdicts by gemma3:27b (Gemma Terms of Use). Both ran locally with temperature 0. The generated text is
redistributed under the terms of the source text it was derived from. The raw response caches are not part of the
release (see `RELEASE_NOTES.md`). No human annotation is included; the audit sheet is empty for authors or users to fill.
